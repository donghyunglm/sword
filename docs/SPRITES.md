# 최종 스프라이트 교체

현재 제공받은 검사·늑대·멧돼지·숲의 수호수 시트와 지역 배경 3장을 사용한다. 아직 없는 후반 캐릭터는 임시 2D 도형으로 표시한다.

새 이미지가 준비되면 `assets/images`에 넣고 `assets/sprites.json`에 설정한다.
`sprites.example.json`은 **구조를 보여주는 예시**다. 현재 적용된 설정은 `sprites.json`에 있다.

## 한 장짜리 PNG

```json
{
  "player": {
    "file": "images/hero.png",
    "draw_width": 48,
    "draw_height": 64,
    "offset_y": 8
  }
}
```

## 가로 프레임과 방향별 행

```json
{
  "player": {
    "file": "images/hero_sheet.png",
    "frame_width": 32,
    "frame_height": 32,
    "frames": 4,
    "fps": 10,
    "direction_rows": {"down": 0, "left": 1, "right": 2, "up": 3},
    "draw_width": 48,
    "draw_height": 48
  }
}
```

행 번호는 **이미지 위쪽부터 0**이다. 각 행의 프레임 수와 크기는 동일해야 한다.
상태별 행은 `state_rows`로 지정할 수 있다. `idle`, `walk`, `dash`, `slash`(주인공),
`chase`, `tell`, `charge`, `recover`, `approach`, `weak`(적/보스) 상태를 사용한다.
상태 행을 지정하면 방향 행보다 우선한다. 아래 `animations` 형식은 상태와 방향을 함께 지정한다.

## 다른 앱에 제작 요청할 권장 규격

숲 캐릭터용 권장 규격이다. 요새와 성역에는 마법사·파수병·기사·드래곤 시트가 추가된다. 모든 PNG는 **투명 배경, 픽셀 아트가 아닌 부드러운 2D 탑다운 시점, 같은 캐릭터 비율과 팔레트**, 그림자·배경 없이 만든다. 한 프레임은 정사각형이며 캐릭터 발 위치가 프레임마다 같은 곳에 오도록 정렬한다. 프레임 사이 간격·테두리·텍스트는 넣지 않는다.

| 대상 | 한 프레임 | 상태별 가로 프레임 | 방향 | FPS |
|---|---:|---|---|---:|
| 주인공 | 64×64px | 대기 4, 걷기 6, 대시 4, 참격 5 | 아래·왼쪽·오른쪽·위 | 대기 6, 걷기 10, 대시 18, 참격 12 |
| 늑대 | 48×48px | 대기/추적 공용 4 | 아래·왼쪽·오른쪽·위 | 8 |
| 멧돼지 | 64×64px | 추적 4, 예고 2, 돌진 3, 회복 3 | 아래·왼쪽·오른쪽·위 | 8/5/14/7 |
| 수호수 보스 | 96×96px | 접근 4, 예고 3, 돌진 4, 약점 4, 회복 3 | 아래·왼쪽·오른쪽·위 | 7/5/14/8/6 |

**행 배치:** 한 상태마다 아래·왼쪽·오른쪽·위 순서로 4행을 묶는다. 상태 묶음 순서는 위 표 순서. 열은 해당 캐릭터의 최대 프레임 수로 통일하고, 적은 프레임을 쓰는 행의 나머지 칸은 투명하게 둔다. 예를 들어 주인공 시트는 6열×16행, 즉 **384×1024px**이다. 늑대 4열×4행=192×192px, 멧돼지 4열×16행=256×1024px, 보스 4열×20행=384×1920px이다. 이는 권장 제작 규격이며 최종 시트에 맞춰 설정을 조정할 수 있다.

주인공 잔영은 주인공 시트를 반투명하게 재사용한다. 별도의 잔영 시트는 필요 없다. 검을 주인공과 같은 프레임에 넣어도 되지만, 이동·대시 프레임에서 검 끝이 프레임 밖으로 잘리지 않게 한다. 참격의 청록색 궤적은 게임이 별도로 그린다.

```json
{
  "player": {
    "file": "images/hero_sheet.png",
    "frame_width": 64,
    "frame_height": 64,
    "frames": 6,
    "draw_width": 64,
    "draw_height": 64,
    "offset_y": 8,
    "direction_order": ["down", "left", "right", "up"],
    "animations": {
      "idle": {"row": 0, "frames": 4, "fps": 6},
      "walk": {"row": 4, "frames": 6, "fps": 10},
      "dash": {"row": 8, "frames": 4, "fps": 18},
      "slash": {"row": 12, "frames": 5, "fps": 12}
    }
  }
}
```

`row`는 이미지 위에서부터 0이며, 상태의 **아래 방향 첫 행**이다. `animations`의 각 상태는 서로 다른 프레임 수와 속도를 쓸 수 있다. 이미지가 아직 없으면 기존 `assets/sprites.json`의 빈 설정을 유지한다.

사용할 수 있는 항목은 `player`, `wolf`, `boar`, `guardian`, `mage`, `sentinel`, `knight`, `dragon`, `forest`, `fortress`, `sanctuary`다.
guardian, knight, dragon은 기본 캐릭터보다 2배 크기로 표시하므로 예시의 `draw_width` 42는 실제 84px로 표시된다.
설정하지 않은 항목은 임시 2D 도형을 계속 사용한다.

## 판정과 그래픽은 별도

- 실제 판정은 `player.py`, `enemy.py`, `boss.py`의 `radius`와 `config.py`의 참격 반경을 사용한다.
- 이미지 크기를 바꿔도 판정 반경이 자동으로 바뀌지 않는다. F1을 눌러 실제 판정을 확인한다.
- 잔영은 주인공 이미지의 반투명 복사본이다. 별도 잔영 시트는 필요하지 않다.
- 임시 캐릭터의 도형·검 연출은 외부 주인공 PNG를 사용하면 생략한다.
- 이미지는 프로젝트 내에서만 읽으며 외부 다운로드나 API 호출을 하지 않는다.
