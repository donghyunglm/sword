# 구현 기준

원본 PPT는 보존한다. 이후 대화에서 정한 수정안을 원본의 오래된 설명보다 우선한다.

- Python + pico2d, 평면 2D 탑다운.
- WASD/방향키 이동, Space 대시, J 잔영 참격. Z 참격은 사용하지 않는다.
- 대시 자체에는 피해가 없다. 활성 잔영 경로는 하나다.
- 적중 판정 확정 후 다중 적중 또는 보스 약점 성공 시 재대시한다.
- 숲은 몬스터 처치로 봉인을 푼다. 요새·성역은 마물 처치에 더해 결정 파괴와 연결 단자 작동이 필요하다. 장치 주변을 비워 자동 정화하는 방식은 사용하지 않는다.
- 현재 구현 범위: 숲·요새·성역 15라운드, 적 4종, 지역 보스 3종, 장치·탄환·위험 구역, 강화 3종, 재도전과 클리어.
- 사용자가 제공한 숲 캐릭터 시트와 지역 배경 3장을 적용했다. 아직 없는 후반 캐릭터는 임시 2D 도형으로 둔다. 그래픽과 판정은 분리한다.
- 게임 판정은 렌더러와 분리해 창 없이 자동 검사한다.

참고: pico2d https://github.com/2DGP/pico2d / https://pypi.org/project/pico2d/
