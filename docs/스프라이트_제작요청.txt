Python pico2d 2D 탑다운 액션 게임 「잔영의 검」에 쓸 부드러운 2D 일러스트 스프라이트 시트를 만들어 주세요. 픽셀 아트는 사용하지 않습니다.

공통 조건:
- 정면·왼쪽·오른쪽·뒷면의 탑다운 4방향. 행 순서는 아래, 왼쪽, 오른쪽, 위.
- 투명 PNG. 배경·그림자·텍스트·격자선·프레임 간 공백 없이 균일한 격자.
- 각 프레임에서 발 위치와 몸 중심을 일정하게 정렬. 실루엣, 의상, 색, 무기를 모든 행에서 일관되게 유지.
- 각 상태를 4방향 행 한 묶음으로 배치. 상태 묶음은 아래 순서대로 배치.
- 한 캐릭터의 모든 행은 같은 열 수로 만들고, 사용하지 않는 마지막 칸은 투명하게 비워 둘 것.
- 결과물은 캐릭터별 시트 PNG와 각 상태의 프레임 수/행 번호가 적힌 설명을 함께 제공.

1) 주인공: 날렵한 검을 든 영웅. 한 칸 64×64px, 전체 6열×16행=384×1024px.
상태 순서 및 각 방향별 실제 프레임: 대기 4, 걷기 6, 대시 4, 검격 5.
대시 자세는 앞으로 빠르게 미끄러지는 느낌. 검격은 검을 휘두르는 자세. 잔영은 게임이 주인공 시트를 반투명하게 재사용하므로 따로 만들지 않아도 됨.

2) 늑대: 한 칸 48×48px, 전체 4열×4행=192×192px.
추적/이동 4프레임. 4방향.

3) 멧돼지: 한 칸 64×64px, 전체 4열×16행=256×1024px.
상태 순서 및 각 방향별 프레임: 추적 4, 돌진 예고 2, 돌진 3, 회복 3.
예고는 몸을 낮춰 방향을 고정한 모습. 회복은 돌진 직후 빈틈이 보이는 모습.

4) 숲의 수호수 보스: 큰 갑옷 멧돼지 또는 신수 느낌. 한 칸 96×96px, 전체 4열×20행=384×1920px.
상태 순서 및 각 방향별 프레임: 접근 4, 돌진 예고 3, 돌진 4, 약점 노출 4, 회복 3.
보스는 빠르게 따라다니는 인상이 아닌 무겁고 위엄 있는 움직임. 약점 노출 때 금빛 핵 또는 균열이 뚜렷이 보이게.

5) 추가 캐릭터: 요새 마법사, 돌진 파수병, 봉인 수호기사, 침식된 드래곤. 모두 같은 화풍의 2D 탑다운 투명 PNG로 제작. 마법사는 사격, 파수병은 돌진 예고/돌진/회복, 기사는 접근/예고/돌진/약점/회복, 드래곤은 대기/예고/공격/약점/회복 자세가 구분되어야 함. 정확한 시트 크기는 앞의 캐릭터를 확인한 뒤 합의.

스타일: 어두운 숲·요새·성역 배경에서 읽히는 선명한 실루엣, 청록색 잔영/검격 연출과 조화되는 판타지 2D 일러스트. 매끈한 선과 자연스러운 명암. 픽셀 아트, 등각 투시, 3D 렌더 느낌은 피할 것.

중요: 첫 결과에서 주인공 1장만 먼저 만들어 4방향/각 상태/투명 배경/프레임 정렬을 확인한 뒤 같은 화풍으로 적과 보스를 제작해 주세요.
