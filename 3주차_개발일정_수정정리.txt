잔영의 검 — 3주 차 종료 기준 개발 일정 수정 정리
작성 기준: 2026-11-17 / 이번 주 개발은 불화살 쿨타임 조정으로 마감

1. 원래 발표 PPT의 일정
출처: 잔영의_검_발표최종_콘텐츠범위수정.pptx, 6·8번 슬라이드

1주 차: 이동, 잔영 전투, 적 행동, 벽 충돌
2주 차: 숲 라운드 배치, 봉인 장치, 출구 전환
3주 차: 숲 5라운드 연결, 수호수 보스, 강화, 결과 화면
4주 차: 오류·밸런스·연출 수정, 첫 지역 최종 완성
제출 목표: 숲 5라운드와 보스, 강화, 재도전, 클리어까지 연결
요새·성역을 포함한 전체 15라운드는 이후 확장 기획이었다.

참고: 상세기획서_개발설계보완.pptx 32번 슬라이드는
2주 차 숲 완료 → 3주 차 요새 → 4주 차 성역 확장 검토로 작성되어 있다.
발표용 일정과 상세기획서의 확장 시점이 달라, 다음 발표에서는 통일한다.

2. 개발 과정에서 달라진 방향

지역 구성: 숲 5라운드 중심 → 4개 지역, 총 15라운드 구성으로 변경
현재 구성: 마족화된 숲 3개 / 불타는 요새 4개 / 혹한의 땅 4개 / 용의 성 4개
전투: 잔영 참격에 기본 검격, 원거리 원소 공격, 보스 패링·반격 추가
성장: 단순 강화 선택 중심에서 재료 획득 → 원소석 제작 → 슬롯 장착으로 변경
진행: 라운드 전투에 거점 귀환, 보관함, 대장간, 지역 출발 지도 연결
UI: 인벤토리에서 검·원소석·회복약을 1~5 단축 슬롯으로 드래그해 배치

3. 수정된 4주 개발 일정
아래는 현재 작업 내용을 기준으로 재정리한 단계다.
1·2주 차 항목은 새로 해야 할 작업이 아니라 선행 개발 내용을 묶은 것이다.

[1주 차 — 기본 전투와 이동 기반]
이동, 대시, 잔영 생성·참격, 적 추적·돌진, 충돌 처리 구현
완료 기준: 이동·대시·잔영 공격의 기본 흐름 확인

[2주 차 — 지역 전투와 진행 기반]
라운드 연결, 적·보스 전투, 스프라이트 적용, 저장·재도전 기반 구현
완료 기준: 전투에서 다음 구역으로 넘어가는 흐름 확보

[3주 차 — 확장 기능 연결 / 이번 주 마감]
4개 지역 15라운드 구성과 지역 자산 연결
거점, 출발 지도, 보관함·인벤토리, 대장간 제작 연결
원소 원거리 공격, 방어막, 패링·반격 전투 연결
인벤토리 드래그를 통한 단축 슬롯 배치·교환·저장 구현
폰트·패링 아이콘·슬롯 숫자와 스킬 이미지 배치 수정
전 라운드 이동 방향 표시 및 제작 후 충돌 끼임 수정
제작하기 → 5초 대기 → 바닥 완성품 생성 → E 획득 구현
발표용 불씨 조각 3개·화염의 핵 1개를 거점에서 한 번 지급
마지막 조정: 불화살 재사용 대기 3초 → 2.5초
마감 기준: 계획한 기능의 연결을 마치고 4주 차 통합 검증으로 전환

[4주 차 — 통합 검증과 완성도 개선 / 예정]
우선순위 1: 새 게임부터 최종 보스까지 직접 완주하며 진행 막힘 확인
  - 출구 개방, 필수 상자·보스 전리품, 지역 해금, 제작 재료 수량 확인
  - 제작·획득·슬롯 배치·장비 변경 후 저장과 이어하기 확인
  - 제작 후 이동, 벽 충돌, 방향 전환, 실패·재도전 확인
우선순위 2: 전투 밸런스와 조작감 조정
  - 불화살 2.5초 체감, 화살 소모·보급, 냉기와 기본 공격의 차이 검증
  - 보스 패턴·방어막·패링·반격 기회의 가독성과 난이도 조정
우선순위 3: UI·연출 정리와 발표 준비
  - 글자·아이콘 겹침, 안내 문구, 임시 표현 정리
  - 실제 플레이 영상 촬영, 변경된 기획·일정으로 발표 자료 정리
완료 기준: 새 게임부터 최종 보스·결과 화면까지 중단 없이 플레이 가능
운영 원칙: 신규 지역·신규 성장 시스템 확장보다 현재 범위의 오류 수정 우선

4. 현재 상태를 발표할 때의 표현

“초기 계획은 숲 5라운드의 완성이었으나, 개발 과정에서 지역별 재료 수집과
거점 제작이 이어지는 4개 지역 15라운드 구조로 확장했습니다.
3주 차에는 전투·원소석 제작·인벤토리·지역 이동 기능을 연결했고,
4주 차에는 전체 진행 검증과 전투 밸런스, UI 및 발표 자료를 정리할 계획입니다.”

주의: 기능 구현과 게임 전체의 최종 완성은 구분한다.
현재 테스트 통과만으로 전체 15라운드의 완주 안정성과 재미 검증이 끝난 것은 아니다.
발표용 지급 재료는 시연 편의를 위한 설정이며 최종 재료 파밍 밸런스와 구분한다.
