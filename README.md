# 잔영의 검

Python + **pico2d**로 구현한 2D 탑다운 액션 게임이다.
좌클릭으로 검격하고, 스페이스 대시로 잔영을 남긴 뒤 우클릭으로 발동한다. 대시 자체에는 피해가 없다.
몬스터 처치 조건을 달성하면 봉인이 풀린다. 문을 지나 연결 통로를 걸어 다음 구역으로 간다.

기본 잔영 검격은 오래된 잔상부터 약 0.045초 간격으로 베고 사라진다. 2-4는 자동 잔영 체험,
3-6은 패링·속성 방어막·원거리 연사 체험이다.

## 현재 구현 범위

- 숲 **5라운드**: 늑대 전투, 이정표 방어, 멧돼지 돌진, 봉인석 동시 작동, 수호수 보스.
- 요새 **5라운드**: 마법사 탄환 제거, 연결 주술 단자, 생성 결정, 혼합 전투, 봉인 수호기사.
- 성역 **6라운드**: 공급 결정, 연결 단자, 화염탄과 낙하 공격, 드래곤 1차전, 3-6 탑다운 최종전.
- 늑대 추적 / 멧돼지 방향 예고·돌진·회복.
- 한 경로의 잔영, 약 1.2초 유지, 순서대로 사라지는 연속 공격과 대상당 1회 피해.
- 1-4에서는 두 숲 봉인석을 한 번의 연속 공격으로 작동시킨다. 2-3의 결정은 각각 늑대·마법사·파수병을
  최대 두 번 생산한다. 생산지를 정화하면 2-4 증원이 줄고,
  성역의 공급선을 끊으면 3-5 드래곤 체력이 줄어든다.
- 1-5 보상 **정화의 검**은 요새의 탄환·결정 공격을 연다. 2-3 뒤에 **냉기 검**, 2-5 뒤에
  **파쇄 검**을 얻는다. 파쇄 검은 성역 결정을 한 번에 깰 수 있다.
- 전투 중 1~3으로 무기 전환: 기본 검은 빠른 공격, 냉기 검은 주변 적을 잠시 빙결시킨 뒤 둔화하고 보스 준비 동작을 지연,
  파쇄 검은 느리지만 갑옷 적·보스 약점·결정에 강하다. 임시 아이콘과 서로 다른 검광을 사용한다.
- 다중 적중(2마리 이상)과 보스 약점 성공 시 즉시 재대시. 빗나감 0.8초, 단일 적중 0.5초 대기.
- 수호수: 접근, 돌진 예고, 직선 돌진, 금빛 약점, 회복. 약점 창마다 1회 피해.
- 참격 범위 / 잔영 유지 / 이동 속도, **선택 강화 3종**. 선택 화면은 숲 수호수와 요새 기사 뒤의 휴식 지점에 표시한다.
- 실패 시 해당 구역 시작 상태로 재도전. 연결 통로를 지나면 체력이 회복된다.
- 타이틀, 이어하기, 일시정지, 연습장, 실패·클리어 화면.
- 타이틀 F2에서 원하는 라운드를 골라 체험할 수 있다. 체험 진행은 기존 저장을 변경하지 않는다.
- 자동 진행 저장과 최초 완료 보상 중복 방지. 손상된 저장은 보존하고 안내.
- 제공받은 검사·늑대·멧돼지·마법사·파수병·지역 보스 3종 시트와 숲·요새·성역 배경 적용.
- 길을 막는 지형은 숲의 뒤틀린 나무뿌리, 요새의 무너진 석주, 성역의 침식 기둥 이미지로 표시한다. 충돌 사각형은 F1 판정 표시에서만 볼 수 있다.
- 결정·단자·봉인의 문·탄환·전투 효과 이미지 적용. 판정 안내선과 일부 효과는 게임에서 직접 그린다.
- 제공받은 투명 PNG UI 아이콘 16개를 체력·대시·검격·무기·봉인 진행도·보스 체력·안내창에 적용했다. 글자는 코드에서 표시한다.
- 합성 효과음 사용.

3-6에는 얼음·불 드롭이 있다. E로 획득하고 휠·아이템 창으로 교체한다. 대시 후 우클릭하면 각 잔영이 커서 지점을 향해 탄환을 발사하고 사라진다. 정상 재사용 시간은 3초다.

3-6 전용 패링 규칙:
- F를 누른 뒤 0.18초 안에 드래곤 몸통 돌진이 닿으면 패링 성공. 실패 시 재시도 대기는 0.75초다.
- 방어막이 깨지고 드래곤은 2초 스턴된다. 낙하 공격도 이 동안 중단된다.
- 깨진 방어막 속성을 임시로 부여받아 장비 교체 없이 잔영을 2회 연속 사용할 수 있다. 첫 발사 뒤 즉시 재대시 가능, 두 번째 뒤 정상 쿨타임 복귀.
- 스턴 중 보스 뒤쪽에서 첫 직접 검격 성공 시 추가 피해 +3. 패링당 한 번만 적용한다.
- 방어막 내구도는 8. 기본(백청색)·얼음(파랑)·불(주황) 중 획득한 속성으로 4초마다 무작위 변경되며 0.7초 전 다음 속성을 알린다. 같은 속성 공격으로도 파괴할 수 있다.
- 기본/파쇄 검은 기본 속성, 냉기 검·얼음탄은 얼음 속성, 화염탄은 불 속성으로 방어막을 공격한다.
- 3-6의 기본 잔영은 더 밝게 표시하고 얼음탄은 결정과 파편 형태로 표현한다.
원본 PPT는 수정하지 않는다. 문서의 오래된 ‘장치 주변 자동 정화’ 대신 최신 합의인
**몬스터 처치 → 봉인 해제 → 다음 라운드** 흐름을 사용한다.

## 이 PC에서 바로 실행

VS Code에 `sword` 폴더를 열어 둔 상태에서:

1. `main.py`를 연다.
2. Python 인터프리터가 `.venv/Scripts/python.exe`인지 확인한다.
3. **F5**를 누르고 `잔영의 검 - 게임 실행`을 선택한다.

Python/디버거 확장이 없다면 VS Code의 추천 확장 `Python`, `Python Debugger`를 설치한다.
디버거 없이 실행하려면 터미널에서:

```powershell
.\.venv\Scripts\python.exe main.py
```

또는 `run_game.cmd`를 더블클릭한다. 게임 창에서 **Enter**를 눌러 시작한다.

현재 `.venv`는 이 PC에 이미 설치된 Python 3.14와 pico2d 1.5.1을 사용한다.
다른 PC로 옮길 때 `.venv`를 복사하지 말고 새로 만든다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 조작

| 키 | 기능 |
|---|---|
| WASD / 방향키 | 8방향 이동 |
| 마우스 커서 | 검격·원거리 스킬 조준 (이동 방향과 독립) |
| Space | 누르고 있는 이동 방향으로 대시. 멈춰 있으면 커서 방향 대시 |
| 좌클릭 | 검격 (기존 라운드에서는 잔영이 있으면 잔영 검격) |
| 우클릭 | 원소 장착 시 커서 방향 원거리 연사 / 검 장착 시 잔영 발동 |
| F | 3-6에서 몸통 돌진 패링 |
| E | 가까운 얼음·불 원소 획득 |
| 휠 | 획득한 검·원소 순환 교체 |
| Tab | 아이템 창 열기·닫기. 전투 일시정지 상태에서 클릭으로 교체 |
| 1 / 2 / 3 | 검 선택 / 보스 뒤 휴식 화면에서는 강화 선택 |
| 4 / 5 | 획득한 얼음 / 불 원소 장착 (왼쪽 위 슬롯 클릭도 가능) |
| W / ↑ | 문을 통과한 뒤 연결 통로를 따라 다음 구역으로 이동 |
| Esc | 전투 일시정지 / 타이틀에서는 종료 |
| R | 실패 화면 또는 일시정지 중 현재 라운드 재시작 |
| Q | 일시정지·결과·강화 화면에서 타이틀로 |
| C | 타이틀에서 이어하기 |
| T | 타이틀에서 연습장(저장 영향 없음) |
| F2 | 타이틀에서 라운드 체험 선택(저장 영향 없음) |
| ↑ / ↓, Enter | 라운드 체험 목록 선택 / 시작 |
| F1 | 판정 범위·경로 점 표시 |
| M | 효과음 켜기/끄기 |

연습장부터 하려면 `python main.py --training`으로 실행할 수도 있다.
3-6 원소만 바로 시험하려면 `python main.py --element-demo`로 실행한다. 기존 진행 저장은 유지된다.
2-4의 검격·자동 잔영 전투만 시험하려면 `python main.py --combat-demo`로 실행한다. 이 구간에서는 좌클릭이 즉시 검격이며, Space 대시 후 잔영이 약 0.35초 뒤 자동으로 벤다.

### 전투 팁

- 대시 직후 바로 베거나, 적이 남긴 경로에 들어오도록 잠깐 기다렸다가 벤다.
- 잔영 검격은 지나온 경로의 오래된 자리부터 순서대로 공격한다. 적이 경로에 들어올 때 J를 눌러 보자.
- 잔영이 남아 있는 동안 새 대시는 불가능하다. 사용하거나 만료된 뒤 재충전한다.
- 다중 적중 재충전은 **연속 검격이 끝난 순간**에 발생한다.
- 멧돼지는 돌진 또는 회복 중에 참격을 맞히면 2피해로 한 번에 처치할 수 있다.
- 요새부터 마법 탄환을 참격으로 지울 수 있다. 연결 단자 두 개는 **한 번의 참격 경로**에 함께 포함해야 작동한다.
- 결정은 두 번 베어 파괴한다. 드래곤은 공격 예고를 피한 뒤 금빛 약점이 열렸을 때 공격한다.
- 모든 선택 강화가 최대 단계라면 강화 화면에서 **Enter**를 눌러 다음 라운드로 간다.
- 한 번의 연속 검격으로 3회 이상 적중하면 다음 잔영 검격 범위가 한 번 커진다.
- 보스는 예고 중 계속 쫓아가지 말고, 예고가 끝날 무렵 옆으로 대시해 잔영을 남긴다.
  돌진 직후 금빛 약점이 열리면 J를 누른다. 회복 중 무한 반복 피해는 불가능하다.
- 수호수·기사는 공격 사이에 천천히 위치를 바꾼다. 드래곤은 옆으로 움직이다 내려찍기 때 예고한 위치로 몸을 이동한다.
- 브레스는 드래곤의 입에서 앞으로 뻗어 나가며 보이는 길이만큼 피해를 준다. 내려찍기는 착지 순간에 충격파와 피해가 발생한다.
- 처치 목표를 채운 뒤 위쪽의 청록색 문으로 직접 이동해야 라운드를 완료한다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | pico2d 창, 키 입력, 고정 시간 간격 반복 실행 |
| `game.py` | 화면 상태, 라운드 전환, 강화·재도전·저장 연결 |
| `combat.py` | 대시·잔영·참격·피격 판정 |
| `player.py`, `afterimage.py` | 본체 상태와 경로·참격 상태 |
| `enemy.py`, `boss.py` | 적 2종과 수호수 행동 |
| `geometry.py` | 좌표, 거리, 벽 충돌과 대시 구간 검사 |
| `stage.py`, `data/stages.json` | 16라운드 배치·생성·처치 목표 |
| `device.py`, `projectile.py`, `late_bosses.py` | 후반 장치·탄환·기사·드래곤 |
| `renderer.py` | HUD, 맵, 임시 2D 캐릭터·참격·메뉴 |
| `sprite_bank.py`, `assets/sprites.json` | 최종 PNG/스프라이트시트 교체 로더 |
| `audio.py` | 임시 합성 효과음 |
| `save_data.py` | 저장 검증·원자적 교체·복원 |
| `tests/` | 렌더러와 독립된 자동 검사 |

이미지 연결 및 이후 그래픽 교체 방법은 [docs/SPRITES.md](docs/SPRITES.md)에 설명했다.
저장과 임시 효과음은 각각 `saves/`, `.cache/`에 생성되며 Git에는 포함하지 않는다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --smoke-test --scene play --frames 60 --capture artifacts/play.png
.\.venv\Scripts\python.exe tools/verify_runtime.py
.\.venv\Scripts\python.exe tools/verify_playthrough.py
```

스모크 테스트는 실제 SDL/pico2d 창과 텍스트·도형 렌더링을 확인한 뒤 자동 종료한다.
선택 가능한 장면: `title`, `play`, `boss`, `upgrade`, `defeat`, `victory`.
자동 테스트에서는 실제 저장 대신 별도 임시 경로를 사용한다.
`verify_runtime.py`는 키 이벤트를 주입해 실제 입력 루프를 검사하고 창을 자동 종료한다.
`verify_playthrough.py`는 체력·피해·처치 수를 조작하지 않는 단순 봇으로 16라운드 진행을 확인한다.
봇 검사는 사람이 느끼는 재미나 난이도의 검증을 대신하지 않는다.
참고: [pico2d 프로젝트](https://github.com/2DGP/pico2d), [패키지 배포](https://pypi.org/project/pico2d/).
