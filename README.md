# 잔영의 검

Python + **pico2d**로 구현한 2D 탑다운 액션 게임이다.
스페이스 대시로 잔영을 남기고 J로 검격을 발동한다. 대시 자체에는 피해가 없다.
몬스터 처치 조건을 달성하면 봉인이 풀리고 출구를 통해 다음 라운드로 간다.

## 현재 구현 범위

- 숲 **5라운드**: 늑대 전투, 다중 적중, 멧돼지 돌진, 혼합 전투, 수호수 보스.
- 늑대 추적 / 멧돼지 방향 예고·돌진·회복.
- 한 경로의 잔영, 약 1.2초 유지, 참격의 지정 타격 시점에 대상당 1회 피해.
- 다중 적중(2마리 이상)과 보스 약점 성공 시 즉시 재대시. 빗나감 0.8초, 단일 적중 0.5초 대기.
- 수호수: 접근, 돌진 예고, 직선 돌진, 금빛 약점, 회복. 약점 창마다 1회 피해.
- 참격 범위 / 잔영 유지 / 이동 속도, **선택 강화 3종**, 각 최대 3단계.
- 실패 시 해당 라운드 시작 상태로 재도전. 출구 진입 후 강화 선택 시 체력 2 회복.
- 타이틀, 이어하기, 일시정지, 연습장, 실패·클리어 화면.
- 자동 진행 저장과 최초 완료 보상 중복 방지. 손상된 저장은 보존하고 안내.
- 간단한 픽셀 임시 그래픽과 합성 효과음. 이미지 없이 실행 가능.

전체 기획의 요새·성역 및 **15라운드와 기사·드래곤은 아직 구현하지 않았다.**
이번 버전은 최근 합의한 4주 완성 범위인 숲 5라운드를 끝까지 플레이하는 버전이다.
원본 PPT는 수정하지 않는다. 문서의 오래된 ‘장치 주변 자동 정화’ 대신 최신 합의인
**몬스터 처치 → 봉인 해제 → 다음 라운드**를 사용하며, 참격은 J키 하나로 통일했다.

## 이 PC에서 바로 실행

VS Code에 `sword` 폴더를 열어 둔 상태에서:

1. `main.py`를 연다.
2. Python 인터프리터가 `.venv/Scripts/python.exe`인지 확인한다.
3. **F5**를 누르고 `잔영의 검 - 게임 실행`을 선택한다.

Python/디버거 확장이 없다면 VS Code의 추천 확장 `Python`, `Python Debugger`를 설치한다.
디버거 없이 실행하려면 터미널에서:

```powershell
.\.venv\Scripts\python.exe main.py
```

또는 `run_game.cmd`를 더블클릭한다. 게임 창에서 **Enter**를 눌러 시작한다.

현재 `.venv`는 이 PC에 이미 설치된 Python 3.14와 pico2d 1.5.1을 사용한다.
다른 PC로 옮길 때 `.venv`를 복사하지 말고 새로 만든다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 조작

| 키 | 기능 |
|---|---|
| WASD / 방향키 | 8방향 이동 |
| Space | 마지막 이동 방향으로 대시하며 잔영 배치 |
| J | 대시 종료 후 잔영 동시 참격 |
| 1 / 2 / 3 | 봉인 해제 후 강화 화면에서 선택 |
| Esc | 전투 일시정지 / 타이틀에서는 종료 |
| R | 실패 화면 또는 일시정지 중 현재 라운드 재시작 |
| Q | 일시정지·결과·강화 화면에서 타이틀로 |
| C | 타이틀에서 이어하기 |
| T | 타이틀에서 연습장(저장 영향 없음) |
| F1 | 판정 범위·경로 점 표시 |
| M | 효과음 켜기/끄기 |

연습장부터 하려면 `python main.py --training`으로 실행할 수도 있다.

### 전투 팁

- 대시 직후 바로 베거나, 적이 남긴 경로에 들어오도록 잠깐 기다렸다가 벤다.
- 잔영이 남아 있는 동안 새 대시는 불가능하다. 사용하거나 만료된 뒤 재충전한다.
- 다중 적중 재충전은 **베기 동작의 타격 판정이 확정된 순간**에 발생한다.
- 멧돼지는 돌진 또는 회복 중에 참격을 맞히면 2피해로 한 번에 처치할 수 있다.
- 3마리 동시 처치 시 다음 참격 범위가 한 번 커진다.
- 보스는 예고 중 계속 쫓아가지 말고, 예고가 끝날 무렵 옆으로 대시해 잔영을 남긴다.
  돌진 직후 금빛 약점이 열리면 J를 누른다. 회복 중 무한 반복 피해는 불가능하다.
- 처치 목표를 채운 뒤 위쪽의 청록색 문으로 직접 이동해야 라운드를 완료한다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | pico2d 창, 키 입력, 고정 시간 간격 반복 실행 |
| `game.py` | 화면 상태, 라운드 전환, 강화·재도전·저장 연결 |
| `combat.py` | 대시·잔영·참격·피격 판정 |
| `player.py`, `afterimage.py` | 본체 상태와 경로·참격 상태 |
| `enemy.py`, `boss.py` | 적 2종과 수호수 행동 |
| `geometry.py` | 좌표, 거리, 벽 충돌과 대시 구간 검사 |
| `stage.py`, `data/stages.json` | 5라운드 배치·생성·처치 목표 |
| `renderer.py` | HUD, 맵, 임시 픽셀 캐릭터·참격·메뉴 |
| `sprite_bank.py`, `assets/sprites.json` | 최종 PNG/스프라이트시트 교체 로더 |
| `audio.py` | 임시 합성 효과음 |
| `save_data.py` | 저장 검증·원자적 교체·복원 |
| `tests/` | 렌더러와 독립된 자동 검사 |

최종 그래픽 교체 방법은 [docs/SPRITES.md](docs/SPRITES.md)에 설명했다.
저장과 임시 효과음은 각각 `saves/`, `.cache/`에 생성되며 Git에는 포함하지 않는다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --smoke-test --scene play --frames 60 --capture artifacts/play.png
```

스모크 테스트는 실제 SDL/pico2d 창과 텍스트·도형 렌더링을 확인한 뒤 자동 종료한다.
선택 가능한 장면: `title`, `play`, `boss`, `upgrade`, `defeat`, `victory`.
자동 테스트에서는 실제 저장 대신 별도 임시 경로를 사용한다.
참고: [pico2d 프로젝트](https://github.com/2DGP/pico2d), [패키지 배포](https://pypi.org/project/pico2d/).
